# Modelo anatômico 3D feminino

Kristen Browne e Heidi Schlehlein, Human Reference Atlas / HuBMAP, *3D Reference Organ Set for Female v1.5* (2023), licenciado sob [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

- DOI: https://doi.org/10.48539/HBM352.BTSQ.586
- Adaptações para a Ajna: uso da pele; malhas simplificadas; coordenadas reposicionadas; posições quantizadas em 16 bits.
- Músculos e esqueleto completo: como o modelo feminino não tem músculos esqueléticos nem todos os ossos, usamos os do *BodyParts3D 4.0* (© The Database Center for Life Science, [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)), deformados para o corpo feminino com os pontos de acupuntura como marcadores (`backend/tools/build_female_layers.py`).
- As posições 3D dos pontos de acupuntura são aproximações geradas a partir do mapa 2D da clínica.
